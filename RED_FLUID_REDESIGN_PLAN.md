# Red Fluid Editorial Redesign Plan

## Goal
Re-art-direct the existing Anuj Harad portfolio into a premium dark editorial software-engineer site using the supplied red/black fluid image as a controlled visual chapter.

## Work
1. Update the global palette to black, charcoal, white, muted gray, and `#FF3045` red; align typography, borders, focus states, and spacing.
2. Keep the current hero structure, but refine the hierarchy, responsive type, technical visualization, cursor lighting, and scroll transition into the red chapter.
3. Replace the current About section with `01 / THE ENGINEER`: fluid background, dark overlays, oversized `ENGINEER` decoration, asymmetric biography, technology line, and minimal identity panel.
4. Redesign Experience as an editorial timeline, then strengthen Projects as the primary proof of engineering ability with large browser frames and clear DataFlow/CloudVault architecture diagrams.
5. Refine Toolkit, Background, and Connect sections into quieter black editorial layouts with consistent red interactions and accessible hover states.
6. Replace Contact with a second, centered fluid-background chapter containing the high-contrast CTA and existing validated contact flow.
7. Verify desktop, mobile, touch, keyboard focus, reduced-motion behavior, no horizontal overflow, real links, and a successful production build.

## Acceptance Criteria
- Visual rhythm follows: dark hero → red engineer chapter → dark content → red contact chapter → footer.
- Fluid image is layered with overlays and remains readable behind all text.
- Red is controlled and reserved for accents, active states, dividers, and CTAs.
- Existing factual portfolio content remains unchanged; no unsupported achievements are added.
