# Anuj Harad — Portfolio

Software Engineer & Full Stack Developer Portfolio website built with React, Vite, Tailwind CSS, and Motion.

## Features
- **Editorial Dark Red Theme**: Modern typography, custom layout, and responsive UI.
- **Featured Live Projects**: Interactive browser mockups for live web applications.
- **Tech Stack & Toolkit**: Skills orbit and categorised toolkit display.
- **Contact & Connect**: Direct phone dialer and mail integration.

## Development Setup

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
